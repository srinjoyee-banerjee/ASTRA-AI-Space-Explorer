# 🌌 ASTRA – AI Space Explorer

An Artificial Intelligence powered web application that identifies astronomical objects from real Sloan Digital Sky Survey (SDSS) observations.

Built using Machine Learning and deployed using Streamlit.

## ✨ Features

- 🌌 Interactive Space Mission Interface
- 🚀 Mission Launch Sequence
- 📡 Deep Space Scanner
- 🤖 Machine Learning Object Classification
- ⭐ Detects:
  - Galaxy
  - Star
  - Quasar
- 📊 Displays Telescope Readings
- 🎯 AI Prediction Confidence
- 📋 Mission Report Generation
- ☁️ Fully Deployed on Streamlit Cloud

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/srinjoyee-banerjee/ASTRA-AI-Space-Explorer.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
