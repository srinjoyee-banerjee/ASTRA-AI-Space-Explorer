# 🌌 ASTRA: AI Space Explorer

## Project Overview
ASTRA: AI Space Explorer is an AI-powered web application that identifies astronomical objects using Machine Learning and Deep Learning. The project classifies celestial objects into Galaxy, Star, or Quasar (QSO) using data from the Sloan Digital Sky Survey (SDSS).

## Features
- 🌌 Predicts Galaxy, Star, or Quasar
- 🤖 Machine Learning & Deep Learning models
- 📊 Interactive Streamlit interface
- 🚀 AI Space Assistant (ASTRA)
- 🔭 Uses real astronomical observations

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Streamlit
- Joblib

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- Artificial Neural Network (ANN)

## Dataset
Sloan Digital Sky Survey (SDSS) Star Classification Dataset
